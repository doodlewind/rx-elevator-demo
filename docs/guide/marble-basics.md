# 如何看懂弹珠图

在正式坐进电梯之前，先发给你一张「地图」。

接下来每一课，我们都会用一种叫**弹珠图（marble diagram）**的小图，把「随时间到来的一串值」画出来。它是 RxJS 世界里最重要的一种图，看懂它，后面的操作符就都变成了「看图说话」。这一节我们专门把它讲透。

## 一条流，画成一行圆圈

想象时间像一条**从左往右流淌的横轴**。在这条轴上，每当流「发出一个值」，我们就画一个**圆圈**。圆圈里写的，就是这次发出的内容 —— 可能是楼层号 `3`，也可能是一个字母 `a`。

<ConceptCard title="弹珠图的四个符号" icon="🛗">

一张弹珠图，你只需要认识四样东西：

- **横轴** = 时间，从左往右流动。越靠右，发生得越晚。
- **圆圈 `○`** = 一次 `next`，即「流发出了一个值」。圈里写的是这个值。
- **竖线 `|`** = `complete`，流**正常结束**了，之后不再发出任何值。
- **叉号 `✕`** = `error`，流**出错中断**了，同样不再继续。

横线 `-` 不是符号，它只表示「这一帧什么都没发生」，是用来拉开时间间隔的空白。

</ConceptCard>

注意三件事：圆圈**不是一次性全画出来**的，而是随着播放头走到对应时间才「到达」；横线处播放头照常前进，但没有值；最后那条**竖线**一出现，这条流的故事就讲完了。

## 用一个字符串写出一条流

每次手写一堆 `{ time, value }` 太啰嗦。RxJS 社区有一种极简的速记法 —— 用一个**字符串**描述整条流，本站也内置了解析它的工具 `parseMarbles`：

```ts
import { parseMarbles } from '@/domain/marble'

// "--a--b--c-|" 这一串，从左到右逐个字符地读：
const events = parseMarbles('--a--b--c-|')
```

怎么读这个字符串？**一个字符 = 一帧**，从左数到右：

- `-` ：这一帧「无事发生」（就是图里的空白横线）。
- 任意普通字符（如 `a`、`3`）：这一帧发出一个值，**值就是这个字符本身**。
- `|` ：这一帧流 `complete`（正常结束）。
- `#` ：这一帧流 `error`（出错中断）。
- `(ab)` ：用括号把几个字符括起来，表示它们在**同一帧**里连续发出。

所以 `"--a--b--c-|"` 的意思是：第 2 帧发 `a`、第 5 帧发 `b`、第 8 帧发 `c`、第 10 帧结束。是不是和上面那张播放器图一模一样？没错，那张图的数据就是这么来的。

## 本站的三行排版约定：上输入 → 中操作符 → 下输出

RxJS 的核心玩法，是用**操作符**把一条流「加工」成另一条流。为了把这个「加工」看清楚，本站所有展示变换的图都遵循同一套**上中下三行**的排版：

<MarbleDiagram :spec="layoutSpec" />

从上往下读：

- **第一行 = 输入流**：加工前的原始流，比如「按钮点击」。
- **第二行 = 操作符**：这一步用的是哪个操作符（这里是 `map`），它像一道横在中间的「加工关卡」。
- **第三行 = 输出流**：原始流穿过操作符之后，变成的新流。

往后每遇到一个新操作符，你都可以条件反射地问自己三句话：**上面进来了什么？中间这道关卡做了什么？下面出去的又变成了什么？** 把这三行对齐着看，操作符就不再神秘了。

<ConceptCard title="本节小结" icon="✅">

- 弹珠图 = 把「随时间到来的一串值」画在一条横轴上。
- 四个符号：**圆圈** = 一个值（next）、**竖线 `|`** = 正常结束（complete）、**叉号 `✕`** = 出错（error）、**横线 `-`** = 空白等待。
- `parseMarbles("--a--b--c-|")` 能用一个字符串快速写出一条流：一个字符一帧。
- 本站所有变换图都按**上=输入流 / 中=操作符 / 下=输出流**三行排列，记住这个看图套路。
